# APD Advance Help App

**APD Advance Help App** — дипломный проект по веб-разработке на Java. Это веб-приложение предназначено для сотрудников службы безопасности. Оно позволяет:

- хранить данные об объектах, где ранее работала группа;
- отображать эти объекты на карте;
- управлять пользователями и их доступом;
- просматривать информацию через веб-интерфейс.

Проект построен с использованием **Spring Boot**, модульной архитектуры и контейнеризации через Docker.

---

## 🔧 Технологии

- Java 17  
- Spring Boot  
- Spring Security  
- Spring Data JPA (Hibernate)  
- PostgreSQL  
- REST API  
- Docker  
- Maven  
- Lombok  
- ModelMapper  

---

## 📁 Структура проекта

- `authorization-module/` — модуль авторизации и безопасности  
- `maps-module/` — логика работы с объектами и отображением на карте  
- `error-handler/` — централизованная обработка ошибок  
- `src/main/` — основной исходный код  
- `pom.xml` — конфигурация Maven  
- `Dockerfile` — конфигурация для Docker-сборки

## 🚀 Запуск проекта

### Вариант 1: Через IDE

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/SergeyCherevichenko/DiplomWorkJava.git
Открой проект в IntelliJ IDEA или другой IDE.

Собери проект:
mvn clean install
Запусти главный класс (обычно Application.java) или выполни:
mvn spring-boot:run
Вариант 2: Через Docker
Собери Docker-образ:
docker build -t apd-help-app .
docker run -p 8080:8080 apd-help-app
